# E0014: a parallel state with a single region

## When

A `#[state]` struct has exactly one `#[region]` field. A parallel state needs at least two.

## Example

```rust
#[state]
pub struct Active {
    #[region]
    output: Output,
}
```

## Message

```text
error: estado::E0014: `Active` has a single `#[region]` field; a parallel state needs at least two
  = help: use `#[substates]` for one level of substates, or add a second region
```

## Fix

Use `#[substates]` if there is only one level of substates, or add the second region.
