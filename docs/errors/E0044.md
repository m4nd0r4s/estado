# E0044: `#[on_done]` on a state that never completes

## When

`#[on_done(S)]` names a state that has no substates and no regions, so no final substate can complete it. Only compound and parallel states complete.

## Example

```rust
#[on_done(Running)]            // `Running` is a leaf
fn running_done(cx: &mut Cx<Self>) -> Next<Self> { goto!(Finished) }
```

## Message

```text
error: estado::E0044: `Running` has no substates, so it never completes
  = help: `#[on_done]` reacts to a final substate of a compound state
```

## Fix

Put `#[on_done]` on the compound or parallel state that holds the `#[terminal]` substate, or use `#[on]` on the leaf.
