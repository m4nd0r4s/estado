# E0001: `#[machine]` is not on an inline module with exactly one `#[root]` enum

## When

`#[machine]` must be applied to an inline module (`mod name { .. }`) that contains exactly one enum marked `#[root]` (ADR 0010). It is reported when the attribute is on something else, the module has no body (`mod player;`), the module has no `#[root]` enum, it has more than one, `#[root]` is on a non-enum, or `#[state]`, `#[root]` or `#[handlers]` is used outside a `#[machine]` module.

## Example

```rust
#[machine(event = Ev)]
mod player {
    pub enum Player {   // missing #[root]
        Idle,
    }
}
```

## Message

```text
error: estado::E0001: machine module `player` has no `#[root]` enum
  = help: mark the enum of the top-level states with `#[root]`
```

Other messages: ``module `player` has no body``, ``a machine has exactly one `#[root]` enum``, ``` `#[machine]` must be applied to an inline module ```, ``` `#[state]` is only valid inside a `#[machine]` module ```.

## Fix

Wrap the machine in an inline module and mark its top-level enum with `#[root]`. A module holds a single machine; put a second one in its own `#[machine]` module. A machine cannot be split across files in v0.

```rust
#[machine(event = Ev)]
mod player {
    #[root]
    pub enum Player {
        #[initial]
        Idle,
    }
}
```
