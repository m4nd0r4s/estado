# E0022: a terminal state cannot transition out

## When

A function of a `#[terminal]` state contains a `goto!`. A final state is the end of its parent's work; only the parent (or an ancestor) leaves it.

## Example

```rust
#[state]
pub enum Phase {
    #[initial] Working,
    #[terminal] Done,
}

#[on(Done)]
fn done(event: &Ev) -> Next<Self> { goto!(Idle) }
```

## Message

```text
error: estado::E0022: `Done` is a terminal state and cannot transition out
  = help: remove the `goto!`, or remove `#[terminal]` from the state
```

## Fix

Move the transition to a handler of the parent compound state (`#[on_done]` or `#[on]`), or drop `#[terminal]`.
