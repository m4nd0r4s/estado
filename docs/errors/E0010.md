# E0010: a level without exactly one `#[initial]` state

## When

Every level of the hierarchy (the `#[root]` enum, each `#[substates]` enum, each `#[region]` enum) has exactly one `#[initial]` variant: the state entered by default. It is reported when a level has none, or more than one.

Spec 3.2 allows omitting `#[initial]` when no `goto!` enters the level without naming a child; until edges are resolved, a level without it is always reported.

## Example

```rust
#[root]
pub enum Player {
    #[initial]
    Idle,
    Active(Active),
}

#[state]
pub struct Active {
    #[substates]
    sub: ActiveSub,
}

#[state]
pub enum ActiveSub {   // no #[initial]
    Playing,
    Paused,
}
```

## Message

```text
error: estado::E0010: `ActiveSub` has no `#[initial]` variant
  = help: mark the variant entered first with `#[initial]`
```

For two initials: ``` `Player` has more than one `#[initial]` variant ```, with a note on the first one.

## Fix

Mark exactly one variant of the level with `#[initial]`.
