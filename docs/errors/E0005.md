# E0005: duplicate handler, or two roles on one function

## When

A state has two functions with the same role (two `#[on(Idle)]`), or one function carries two role attributes. A state has at most one `#[on]`, `#[entry]`, `#[exit]`, `#[always]` and `#[on_done]`.

## Example

```rust
#[on(Idle)]
fn first(event: &Ev) -> Next<Self> { /* .. */ }

#[on(Idle)]            // second handler for `Idle`
fn second(event: &Ev) -> Next<Self> { /* .. */ }
```

## Message

```text
error: estado::E0005: `Idle` already has a handler for this role
  = help: a state has at most one `#[on]`, `#[entry]`, `#[exit]`, `#[always]` and `#[on_done]`
error: estado::E0005: note: the first one
```

## Fix

Merge the two functions into one `match`, or split a function with two roles into one function per role.
