# E0018: more than 32 states can be active at once

## When

The largest configuration the machine can be in holds more than 32 active states (`MAX_ACTIVE_STATES`). The runtime keeps the active configuration inline, in a fixed-size `StatePath`, so the limit is checked when the machine is compiled instead of failing while it runs.

The count is the number of nodes on the active branches: every state and every `#[region]` counts as one, and the root enum does not. A compound state adds one plus its largest substate. A parallel state adds one plus the sum of all its regions, because all regions are active at once, and each region adds one plus its largest state.

The error is reported at the smallest state that is already too big by itself.

## Example

A parallel state with 16 regions of one state each: the parallel state (1), the 16 regions (16) and one state in each region (16) make 33.

```rust
#[state]
pub struct Wide {
    #[region]
    region_0: Part0,
    #[region]
    region_1: Part1,
    // .. up to region_15
}
```

## Message

```text
error: estado::E0018: `Wide` can have 33 states active at once, regions included; the maximum is 32
  = help: use fewer regions, flatten the hierarchy, or move a branch into a child machine
```

## Fix

Reduce the largest configuration to 32 or fewer: merge regions that always move together, flatten nested compound states, or move a branch into a child machine (`#[child]`).
