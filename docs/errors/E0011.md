# E0011: nesting deeper than 16 levels

## When

States nest more than 16 levels deep (`MAX_DEPTH`). A `#[region]` counts as a level because it is a node of the graph. A `#[state]` type that contains itself (directly or through other states) has unbounded depth and is reported too.

## Example

A chain of 17 compound states, each with a `#[substates]` field whose enum holds the next one.

## Message

```text
error: estado::E0011: `L16` is nested 17 levels deep; the maximum is 16
  = help: flatten the hierarchy, or move a branch into a child machine
```

## Fix

Flatten the hierarchy, or move a deep branch into a child machine (`#[child]`, spec 7.4). A recursive state type cannot be one of its own descendants.
