# E0042: transition in an entry or an exit

## When

An `#[entry]` or `#[exit]` function uses a transition macro (`goto!`, `stay!`, `bubble!`, ..). Entries and exits return no value and must not transition; they may call `cx.emit` and `cx.raise`.

## Example

```rust
#[entry(Playing)]
fn entry_playing(cx: &mut Cx<Self>) {
    goto!(Paused);
}
```

## Message

```text
error: estado::E0042: entries and exits cannot transition or return a `Next`
  = help: do the work here and let a handler decide the transition
```

## Fix

Use `cx.raise(event)` to let a handler decide, or move the transition to an `#[on]` or `#[always]` handler.
