# W0002: state with no outgoing edges

## When

A leaf state that is not `#[terminal]` has no way out: neither it nor any of its ancestors has a handler with a `goto!`. Once entered, the machine stays there.

Status: the analysis is implemented and tested; it is switched on once the handler rewrite provides the edges.

## Example

```rust
#[root]
pub enum Player {
    #[initial]
    Idle,
    Stuck,        // no handler leaves it
}
```

## Message

```text
warning: use of deprecated function `__estado_warnings::W0002_Stuck`: estado::W0002: state `Stuck` has no outgoing edges and is not `#[terminal]`; once entered the machine can never leave it (silence with `#[machine(allow(W0002))]`)
```

## Fix

Add a transition out of the state, or mark it `#[terminal]` if ending there is intended.

## Silencing

Prefer `#[machine(allow(W0002))]`: it generates nothing, whatever the lint level. A warning is reported through rustc's `deprecated` lint (ADR 0003), so it also turns into an error under `-D warnings` or `-D deprecated`, and `#![allow(deprecated)]` on the crate or an enclosing module hides every `W` code.
