# E0040: transition macro outside `#[handlers]`

## When

`goto!`, `goto_dyn!`, `stay!`, `bubble!`, `unhandled!`, `defer!`, `reenter!`, `edges!` or `Exiting!` is used where `#[machine]` did not rewrite it: outside a `#[handlers]` function of a `#[machine]` module. The transition macros exist only as markers that `#[machine]` replaces with typed edges; one that expands on its own is a misuse.

## Example

```rust
use estado::prelude::*;

fn not_a_handler() -> Next<Player> {
    goto!(Idle)
}
```

## Message

```text
error: estado::E0040: `goto!` is only valid inside a `#[handlers]` function of a `#[machine]` module
```

## Fix

Move the call into a function of a `#[handlers]` impl in the machine module. `goto_dyn!` and `edges!` inside a handler are not this error: they are not supported yet (E0090). Shared helpers that return a transition (`#[edges]`) are not supported yet (E0090) either: until they are, put the transition in the handler body, or share the decision with a plain function that returns data (an enum or a `bool`) and let the handler call `goto!`.
