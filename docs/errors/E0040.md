# E0040: transition macro outside `#[handlers]`

## When

`goto!`, `goto_dyn!`, `stay!`, `bubble!`, `unhandled!`, `defer!`, `reenter!`, `edges!` or `Exiting!` is used where `#[machine]` did not rewrite it: outside a `#[handlers]` function of a `#[machine]` module. The transition macros exist only as markers that `#[machine]` replaces with typed edges (ADR 0001); one that expands on its own is a misuse.

## Example

```rust
use estado::prelude::*;

fn not_a_handler() -> Next<Player> {
    goto!(Idle)
}
```

## Message

```text
error: estado::E0040: `goto!` is only valid inside a `#[handlers]` function of a `#[machine]` module
```

## Fix

Move the call into a function of a `#[handlers]` impl in the machine module. To share transition code, write a helper marked `#[edges(A | B)]` in the same impl; it returns `Next<Self, edges![A | B]>`.
