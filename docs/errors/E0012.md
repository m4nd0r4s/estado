# E0012: duplicate state name, or a name equal to its id constant

## When

Two nodes of the machine have the same name, or the same `StateId` constant. State names are unique across all levels so that `goto!(Name)` is unambiguous. A region name also counts: it clashes with a state whose constant is the same (`link` and `Link` both give `LINK`).

The `StateId` constants are associated constants of the root type (`Bus::IO`), so a state whose name is already in SCREAMING_SNAKE_CASE (`IO`) would be a variant and a constant with the same name at once. That is reported too.

## Example

```rust
#[state]
pub enum ActiveSub {
    #[initial]
    Playing,
    Idle,          // `Idle` is also a variant of `Player`
}
```

## Message

```text
error: estado::E0012: duplicate state name `Idle`
  = help: state names are unique in a machine so that `goto!(Name)` is unambiguous; rename one
error: estado::E0012: note: `Idle` is first declared here
```

## Fix

Rename one of them. Name states in CamelCase (`Io`, not `IO`).
