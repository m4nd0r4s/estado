# E0003: `goto!` target is not a state

## When

The target of a `goto!` is not a state, region or substate of this machine (a typo, or a state declared in another machine).

## Example

```rust
#[on(Paused)]
fn paused(event: &Ev) -> Next<Self> {
    goto!(Playin)          // there is a state `Playing`
}
```

## Message

```text
error: estado::E0003: `Playin` is not a state of this machine
  = help: did you mean `Playing`?
```

## Fix

Use the name of a state declared in the same `#[machine]` module. The help line suggests the closest one.
