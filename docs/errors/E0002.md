# E0002: the event type is not declared

## When

`#[machine(..)]` has no `event = Type` option. Every machine needs one.

## Example

```rust
#[machine(effect = Cmd)]   // no `event = ..`
mod player {
    #[root]
    pub enum Player {
        #[initial]
        Idle,
    }
}
```

## Message

```text
error: estado::E0002: `#[machine]` does not declare its event type
  = help: add `event = MyEvent`, e.g. `#[machine(event = MyEvent)]`
```

## Fix

Add the event type: `#[machine(event = Ev, effect = Cmd)]`. `effect` and `ctx` are optional and default to `()`.
