# E0090: not supported yet

## When

The machine uses something that is part of the planned macro language but that this version of `estado` does not generate code for. The error says what; it is reported at the offending attribute, state or `goto!`, and the rest of the machine is still checked.

Not supported yet:

- `#[choice]`, `#[on_child_done]`, `#[on_resume]`, `#[invariant]`, `#[edges]`, `#[on_error]`, `#[child]` and `#[children]`.
- `goto_dyn!` and `edges!`, in a handler or in a helper of a `#[handlers]` impl. They are in the prelude, but `#[machine]` does not generate code for them yet.
- Parallel states: a parallel state inside a region of another one; a handler on a region itself (`#[on(region_name)]`); a local transition whose LCA is a parallel state, that is `goto!(P)` from inside `P`, or `goto!(Inside)` from the handler of `P` (use `goto!(.., external)` or a transition inside one region). Transitions between sibling regions are E0021.
- Limits kept in a `u8`: more than 255 `#[after]` timers or `#[invoke]` tasks on one state, or more than 256 substates in a compound state with shallow `#[history]`.
- History: nested `#[history(deep, keep)]`; `goto!(S, history)` on a shallow history whose substates carry data; a constructor that receives a state that holds a deep history.

## Example

```rust
#[handlers]
impl Player {
    #[choice]
    fn decide(_cx: &Cx<Self>) -> Next<Self> { goto!(Playing) }
}
```

## Message

```text
error: estado::E0090: `#[choice]` is not supported yet by this version of `estado`
         = help: it is part of the planned macro language
```

## Fix

Express the same logic with what is supported (`goto!` in an `#[on]` handler, a `match` on the data), or wait for the milestone that adds it.
