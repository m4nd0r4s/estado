# E0017: malformed state attribute

## When

An attribute of a state is malformed: `#[initial(..)]`, `#[after(..)]`, `#[invoke(..)]`, `#[history(..)]` or `#[unhandled(..)]` has the wrong arguments, or a marker is on the wrong item (`#[history]` on a variant or on a state that is not compound, `#[initial]` on a struct, `#[state]` on a function, `#[substates]` on a tuple field). Also reported:

- `#[handlers]` on anything but an inherent `impl` of the root type (`impl Other { .. }`, `impl Trait for Player`): the functions in it take `Self` as the machine.
- A role attribute (`#[on(..)]`, `#[entry(..)]`, ..) on a constant, a type alias or a macro call of the impl block, where it would otherwise leave rustc's bare "cannot find attribute".

## Example

```rust
#[root]
pub enum Player {
    #[initial]
    #[after(1 + 1)]          // missing `=> event`
    Idle,
    #[unhandled(panik)]      // not a policy
    Busy,
}

#[state]
#[history(deep)]             // needs `deep, keep`
pub struct Active { /* .. */ }
```

## Message

```text
error: estado::E0017: invalid `#[after]`: expected `=>`
  = help: write `#[after(duration => event)]`
error: estado::E0017: `panik` is not an unhandled policy
  = help: did you mean `panic`?
error: estado::E0017: deep history needs both `deep` and `keep`
  = help: write `#[history(deep, keep)]`
```

## Fix

Follow the help line. The accepted forms are in spec 6.1.
