# W0004: variant larger than `size_warn` bytes

## When

The data of a variant is larger than `size_warn` bytes (default 128). The machine is one enum, so every state value occupies the size of its largest variant; a big payload makes every transition copy and every `Machine` larger.

The measured size is `size_of` of the tuple of the variant's own fields. A compound or parallel state is measured without its `#[substates]` and `#[region]` fields, which are separate variants reported on their own, so a large leaf warns once and not in every ancestor. The check is made by rustc, so it uses the real layout; the message does not include the size.

## Example

```rust
#[machine(event = Ev)]            // size_warn = 128
mod player {
    #[root]
    pub enum Player {
        #[initial]
        Idle,
        Loaded { samples: [u8; 4096] },   // 4096 bytes
    }
}
```

## Message

```text
warning: use of deprecated associated function `player::__estado_warnings::WarnIf::<true>::W0004_Loaded`: estado::W0004: variant `Loaded` holds more than 128 bytes (`size_warn`); consider boxing its data with `Box<..>`, or raise `size_warn` (silence with `#[machine(allow(W0004))]`)
```

## Fix

Box the data (`Loaded { samples: Box<[u8; 4096]> }`; needs `alloc`), move it into the machine's `ctx`, or raise the limit with `#[machine(size_warn = 4096)]`.

## Silencing

Prefer `#[machine(allow(W0004))]`: it generates nothing, whatever the lint level. A warning is reported through rustc's `deprecated` lint (ADR 0003), so it also turns into an error under `-D warnings` or `-D deprecated`, and `#![allow(deprecated)]` on the crate or an enclosing module hides every `W` code.
