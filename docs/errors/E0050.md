# E0050: regions in typestate mode

## When

`#[machine(typestate)]` generates one type per state, which cannot represent parallel regions. A machine with `typestate` and a `#[region]` field is rejected.

## Example

```rust
#[machine(event = Ev, typestate)]
mod session {
    #[root]
    pub enum Session {
        #[initial]
        Connected(Connected),
    }

    #[state]
    pub struct Connected {
        #[region] link: Link,
        #[region] keepalive: KeepAlive,
    }
    /* .. */
}
```

## Message

```text
error: estado::E0050: regions are not supported in `typestate` mode
  = help: remove `typestate`, or split the regions into separate machines
```

## Fix

Remove `typestate`, or split the regions into separate machines (child machines).
