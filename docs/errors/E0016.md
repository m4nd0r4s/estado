# E0016: invalid `#[machine(..)]` option

## When

An option of `#[machine(..)]` is unknown, given twice, has a bad value, or is a flag given a value (`typestate = true`). Also reported for a code in `allow(..)` that is not a warning of the macros.

Options: `event`, `effect`, `ctx`, `unhandled`, `defer_cap`, `defer_overflow`, `raise_cap`, `fx_inline`, `max_microsteps`, `size_warn`, `typestate`, `infallible`, `version`, `allow`.

## Example

```rust
#[machine(event = Ev, defer_capp = 4, unhandled = ignor, typestate = true, allow(W0044))]
mod player { /* .. */ }
```

## Message

```text
error: estado::E0016: unknown option `defer_capp`
  = help: did you mean `defer_cap`?
error: estado::E0016: `ignor` is not a valid value of `unhandled`
  = help: did you mean `ignore`?
error: estado::E0016: `typestate` is a flag and takes no value
  = help: write just `typestate`
error: estado::E0016: unknown warning code `W0044` in `allow(..)`
  = help: did you mean `W0004`?
```

## Fix

Follow the help line. The warning codes are `W0001`, `W0002`, `W0003`, `W0004`, `W0005`, `W0010`.
