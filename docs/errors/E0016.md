# E0016: invalid `#[machine(..)]` option

## When

An option of `#[machine(..)]` is unknown, given twice, has a bad value, or is a flag given a value (`tracks_active = true`). Also reported for a code in `allow(..)` that is not a warning of the macros.

Options: `event`, `effect`, `ctx`, `unhandled`, `defer_cap`, `defer_overflow`, `raise_cap`, `fx_inline`, `max_microsteps`, `size_warn`, `typestate`, `infallible`, `tracks_active`, `version`, `allow`.

Flags take no value: `tracks_active`, `typestate` and `infallible` (write `#[machine(event = Ev, tracks_active)]`). The other options take a value: a type (`event`, `effect`, `ctx`), a number (`defer_cap`, `raise_cap`, `fx_inline`, `max_microsteps`, `size_warn`, `version`), one of a fixed set of words (`unhandled`, `defer_overflow`), or a list of warning codes (`allow(..)`). A number that does not fit its type is also reported here.

## Example

```rust
#[machine(event = Ev, defer_capp = 4, unhandled = ignor, tracks_active = true, allow(W0044))]
mod player { /* .. */ }
```

## Message

```text
error: estado::E0016: unknown option `defer_capp`
  = help: did you mean `defer_cap`?
error: estado::E0016: `ignor` is not a valid value of `unhandled`
  = help: did you mean `ignore`?
error: estado::E0016: `tracks_active` is a flag and takes no value
  = help: write just `tracks_active`
error: estado::E0016: unknown warning code `W0044` in `allow(..)`
  = help: did you mean `W0004`?
```

## Fix

Follow the help line. The warning codes are `W0001`, `W0002`, `W0003`, `W0004`, `W0005`, `W0010`.
