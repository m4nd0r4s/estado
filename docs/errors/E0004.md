# E0004: `#[on(S)]` with an unknown state

## When

A role attribute (`#[on]`, `#[entry]`, `#[exit]`, `#[always]`, `#[on_done]`) names a state that does not exist in this machine.

## Example

```rust
#[handlers]
impl Player {
    #[on(Plying)]          // there is a state `Playing`
    fn playing(event: &Ev) -> Next<Self> { /* .. */ }
}
```

## Message

```text
error: estado::E0004: `Plying` is not a state of this machine
  = help: did you mean `Playing`?
```

## Fix

Fix the name; the handler belongs to the state the attribute names.
