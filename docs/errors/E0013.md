# E0013: a state mixes `#[substates]` and `#[region]`

## When

A `#[state]` struct is either compound (one `#[substates]` field) or parallel (two or more `#[region]` fields), never both. Reported when it has both kinds of field, more than one `#[substates]` field, or one field with both markers.

## Example

```rust
#[state]
pub struct Active {
    #[substates]
    sub: Sub,
    #[region]
    extra: Extra,
}
```

## Message

```text
error: estado::E0013: `Active` has both `#[substates]` and `#[region]` fields
  = help: a state is compound or parallel, never both; wrap the regions in a substate
```

## Fix

Keep one kind. To have both, wrap the regions in a substate: a state of the `#[substates]` enum that is itself parallel.
