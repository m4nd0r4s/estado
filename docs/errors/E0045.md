# E0045: `reenter!`, `defer!`, `bubble!` or `unhandled!` in `#[always]` or `#[on_done]`

## When

`#[always]` and `#[on_done]` react to the state itself, not to an event, so only `stay!()` and `goto!` mean something there. `reenter!()`, `defer!()`, `bubble!()` and `unhandled!()` have no event to re-enter on, defer, pass up or leave unhandled (ADR 0013 item 3).

## Example

```rust
#[always(Idle)]
fn always_idle(cx: &mut Cx<Self>) -> Next<Self> {
    reenter!()
}
```

## Message

```text
error: estado::E0045: `reenter!` has no meaning in `#[always]` and `#[on_done]`
  = help: these handlers react to their state, not to an event: only `stay!()` and `goto!` are allowed
```

## Fix

Return `stay!()` to do nothing, or `goto!(..)` (`goto!(.., external)` for a self-transition that re-enters the state).
