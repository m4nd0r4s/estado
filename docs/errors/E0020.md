# E0020: `goto!` or `#[initial]` is missing data

## When

A state that has fields is entered without a value for them: a `goto!` that does not give every field of the state (or of an intermediate state the transition enters), or a state with fields that is entered through its `#[initial]` and has no `#[initial(with = ..)]` constructor.

## Example

```rust
#[state]
pub struct Active { track: u32, volume: u8, #[substates] sub: ActiveSub }

goto!(Active { track: 1 })     // missing `volume`
```

## Message

```text
error: estado::E0020: `goto!(Active)` needs data for `Active`: missing `volume`
  = help: write `Active { .. }` with a value for each missing field
error: estado::E0020: note: `Active` is declared here
```

## Fix

Give a value for each missing field, or add `#[initial(with = constructor)]` to the state that is entered through its initial.
