# E0015: the type of a `#[substates]` or `#[region]` field is not a `#[state]` enum

## When

The field type must be an enum of this module marked `#[state]`.

## Example

```rust
#[state]
pub struct Active {
    #[substates]
    sub: ActiveSub,
}

pub enum ActiveSub {   // missing #[state]
    Playing,
}
```

## Message

```text
error: estado::E0015: the type of `sub` must be a `#[state]` enum
  = help: add `#[state]` to `enum ActiveSub`
```

When the type is not an enum of the module at all (`sub: u32`), the help says to declare an enum of the substates in this module and mark it `#[state]`.

## Fix

Declare the enum in the machine module and mark it `#[state]`.
