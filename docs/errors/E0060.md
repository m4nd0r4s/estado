# E0060: `async` handler

## When

A handler is declared `async fn`. Handlers are plain functions run to completion by `send` (spec 6.2); asynchronous work goes through `#[invoke]` (spec 7).

## Example

```rust
#[on(Idle)]
async fn idle(cx: &mut Cx<Self>, event: &Ev) -> Next<Self> { /* .. */ }
```

## Message

```text
error: estado::E0060: handlers cannot be `async`
  = help: do asynchronous work with `#[invoke]` and let the result arrive as an event (spec 7)
```

## Fix

Remove `async`; start the work with `#[invoke(task)]` on the state and handle the event that carries its result.
