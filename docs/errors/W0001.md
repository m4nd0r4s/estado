# W0001: state unreachable from the initial state

## When

No chain of edges (`goto!`) leads from the initial configuration to the state. Reported once, at the topmost unreachable state; its descendants are not repeated. A machine that uses `goto_dyn!` is not checked, because its target is only known at run time.

Status: emitted. The edges are the `goto!` occurrences of the analysed handlers; a machine with errors is not checked, because its edge list is incomplete.

## Example

```rust
#[root]
pub enum Player {
    #[initial]
    Idle,
    Active,
    Orphan,       // nothing has `goto!(Orphan)`
}
```

## Message

```text
warning: use of deprecated function `__estado_warnings::W0001_Orphan`: estado::W0001: state `Orphan` is unreachable from the initial state (silence with `#[machine(allow(W0001))]`)
```

## Fix

Add the missing `goto!` to the state, or delete the state.

## Silencing

Prefer `#[machine(allow(W0001))]`: it generates nothing, whatever the lint level. A warning is reported through rustc's `deprecated` lint, so it also turns into an error under `-D warnings` or `-D deprecated`, and `#![allow(deprecated)]` on the crate or an enclosing module hides every `W` code.
