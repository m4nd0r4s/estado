# E0043: malformed `goto!`

## When

The arguments of a transition macro are wrong: a target path whose levels are not nested (`goto!(Idle / Failed)`), `external` with a target that is not the state itself or an ancestor, `history` on a state that records none, an `Exiting![X]` that names a state other than the one that exits, a constructor that does not take exactly one parameter, data written next to the target of a constructor form (`goto!(Failed { reason: 1 }, |old| ..)`: the closure builds the whole value, so the data would be ignored), an unreadable argument, or arguments given to `stay!()`, `bubble!()` and the like. (Spec 6.7 gives the code E0041 to the constructor form in `#[edges]`; E0043 is the code of the other malformed forms.)

## Example

```rust
goto!(Playing, external)       // `Playing` is not an ancestor of the handler's state
```

## Message

```text
error: estado::E0043: `external` needs a target that is the state itself or one of its ancestors, and `Playing` is neither
```

## Fix

With a constructor closure, write the target without data and build the whole value in the closure. Otherwise write one of the accepted forms: `goto!(T)`, `goto!(T { .. })`, `goto!(A { .. } / B { .. })`, `goto!(T, external)`, `goto!(T, history)`, `goto!(T, |old: Exiting![X]| value)`.
