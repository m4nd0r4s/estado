# E0021: transition between sibling regions

## When

A `goto!` goes from a state of one `#[region]` of a parallel state to a state of another region of the same parallel state. The regions of a parallel state are independent; a transition between them has no meaning in the semantics of spec 5.2 (the LCA would be the parallel state itself, and entering one region would exit the other).

## Example

```rust
#[state]
pub struct Up {
    #[region] sender: Sender,
    #[region] receiver: Receiver,
}

#[on(Sending)]
fn on_sending(_cx: &mut Cx<Self>, _event: &Ev) -> Next<Self> {
    goto!(Muted)    // `Muted` is a state of `receiver`
}
```

## Message

```text
error: estado::E0021: `Sending` and `Muted` are in sibling regions of `Up`
         = help: regions never transition each other: raise an event with `cx.raise(..)` that the other region handles
```

## Fix

Raise an event with `cx.raise(..)` and let a handler of the other region react to it (it runs as an internal event after the current microstep, spec 5.4), or move the state so both live in the same region.
