# E0061: `Result` handler without `#[on_error]`

## When

A handler returns `Result<Next<Self>, E>`, and the machine has no `#[on_error(S)]` to turn the `Err` into a transition. This version of `estado` does not support `#[on_error]` yet (it is reported as E0090), so every `Result` handler gets this error.

## Example

```rust
#[on(Idle)]
fn on_idle(_cx: &mut Cx<Self>, _event: &Ev) -> Result<Next<Self>, String> {
    Ok(stay!())
}
```

## Message

```text
error: estado::E0061: a handler returns `Result` but there is no `#[on_error]`
         = help: `#[on_error]` is not supported yet by this version of `estado`: return `Next<Self>` and turn the error into a transition in the body
```

## Fix

Return `Next<Self>` and match on the error in the body, going to the state that handles it with `goto!`.
